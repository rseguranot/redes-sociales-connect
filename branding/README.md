# Activos de marca

Este directorio contiene únicamente una marca neutral de ejemplo.

Para una instalación:

1. Guarde el activo autorizado fuera del repositorio público o en una rama privada.
2. Indique su ruta local en `BrandLogoPath`.
3. Defina `BusinessName`, `BusinessTagline` y `LogoIncludesName` en la configuración local.
4. Ejecute el build/despliegue; no edite componentes React para cambiar la marca.
5. Verifique contraste, proporción, texto alternativo y render dentro de Agent Workspace.

Formatos recomendados: SVG saneado o PNG transparente. Elimine metadatos personales y confirme derechos de uso. No incluya tokens, teléfonos, dominios internos ni nombres de archivos que identifiquen a un cliente.

Consulte [Personalización y marca](../docs/PERSONALIZACION-Y-MARCA.md).
